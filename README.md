# Ledger Storage

AI Insights Ledger storage and repository definitions for Mistralys repositories. 

## What's this?

It is a store for workflow support files used by the [AI Insights](https://github.com/Mistralys/ai-insights) agentic development workflow. 

It contains the following things:

- MCP ledger files.
- Repository-level development strategy.
- Global and repository-level knowledge.
- Lang Graph orchestrator logs & agent dialogues.

## Dual Purpose

This store is used as an implementation archive to keep track of what has been done, and to maintain related knowledge.
